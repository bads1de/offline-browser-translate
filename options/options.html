        🚀 Auto-Translate

        Trigger translation automatically on page load, or on demand for selected text.

        Automatically translate pages
        Translates pages automatically on load, using your own machine. Asks for permission to run on all websites.
        Floating translate button
        A small button appears next to selected text so you can translate it without right-clicking. Enabling this will ask for permission to run on all websites.

          Languages you already read. Your target language is always excluded.

          ⚡ Performance

          Tune batch size and concurrency for your hardware.

          Higher values = fewer API calls, but may hit model limits.

          Lower values = faster visual feedback as translations appear.

          Lower = more consistent translations. Higher = more creative.

          How many translation requests run at once. Higher isn't always faster; it depends on your hardware and server.

          📤 Output Settings

          Control how translations are displayed and how models respond.

          Structured JSON output
          Requests JSON format from the model. Disable if the model struggles with JSON.
          Plain-text fallback
          If a segment keeps coming back malformed, retranslate it as plain text. Slower, but avoids leaving text untranslated.
          Translation glow effect
          Visual indicator when text has been translated on the page.

          💾 Translation Cache

          Reuse stored translations for identical text so repeated content isn't re-translated.

            ⚠️ This browser doesn't support keeping the cache across sessions.

            🧪 Experimental

            These are experimental features and might not fully work.

            📖 Glossary (experimental)

            Force consistent translations for specific terms. Whole-segment matches skip the model entirely; partial matches are added as hints. Only matching terms are sent per request, so a large dictionary is fine.

              ● Unsaved changes

              Import/export uses TSV (Tab-Separated Values): one line per term, with the term and its translation separated by a Tab, e.g. Server Servidor. Any spreadsheet app can save to this format. Add a #target: ja line to limit the file to one target language.
